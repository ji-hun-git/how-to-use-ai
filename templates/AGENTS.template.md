# AGENTS.md

## 명령어
- 설치: `pnpm install`
- 테스트(단일 파일): `pnpm test path/to/file.test.ts`  ← 전체 테스트는 5분 걸리므로 단일 파일 우선
- 린트/타입 체크: `pnpm lint && pnpm typecheck`
- 로컬 실행: `pnpm dev` (포트 3000)

## 코드 규칙 (코드만 봐서는 알 수 없는 것만)
- 날짜는 `dayjs` 말고 `src/lib/time.ts`의 래퍼를 사용 (시간대 버그를 막기 위해)
- API 응답 타입은 `src/types/api.ts`에서만 정의
- 새 의존성은 추가하기 전에 먼저 물어볼 것

## 작업 방식
- 변경 전에 관련 테스트를 먼저 실행해서 현재 상태를 확인할 것
- 버그 수정은 재현 테스트부터 작성할 것
- 커밋 메시지는 Conventional Commits 형식 (`feat:`, `fix:` …)

## 자주 하는 실수 (발견할 때마다 추가)
- `legacy/` 폴더는 수정하지 말 것. 외부 시스템이 직접 참조 중임
- 마이그레이션 파일은 새로 만들기만 하고 기존 파일은 수정하지 말 것
