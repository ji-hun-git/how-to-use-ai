# 메타 프롬프트: AI에게 프롬프트를 쓰게 하기

> 프롬프트를 처음부터 잘 쓰기는 어렵습니다. **AI에게 인터뷰를 받거나 초안을 고치게 하면** 훨씬 빠릅니다.
> 다만 AI가 다듬은 프롬프트도 **직접 시험해 보고 비교한 뒤에** 채택하세요.

---

## A. 인터뷰형: 질문을 받으며 프롬프트 완성하기

```text
나는 ___ 작업을 AI에게 맡기려고 해. 좋은 프롬프트를 같이 만들고 싶어.
역할 · 맥락 · 지시 · 형식 · 제약 · 예시 중 빠진 정보를 한 번에 하나씩 질문해줘.
충분히 모이면 바로 쓸 수 있는 최종 프롬프트를 코드 블록으로 줘.
```

## B. 개선형: 내 프롬프트 고치기

```text
아래 프롬프트를 개선해줘.
1) 먼저 이 프롬프트로 받을 수 있는 나쁜 결과 3가지를 예상해줘. (오해 / 누락 / 지어냄 관점)
2) 그 문제를 막도록 고친 버전을 줘.
3) 무엇을 왜 바꿨는지 표로 정리해줘.

<prompt>
(내 프롬프트)
</prompt>
```

## C. 역설계형: 좋은 결과물에서 프롬프트 뽑기

```text
아래는 내가 원하는 수준의 결과물이야. 이런 결과물을 다시 만들 수 있는 프롬프트를 써줘.
결과물의 독자, 어조, 구조, 분량, 숨은 규칙을 먼저 분석한 다음 프롬프트로 바꿔줘.

<good_output>
...
</good_output>
```

## D. 재사용 템플릿으로 만들기

```text
방금 대화에서 잘 된 부분을 바탕으로, 다음에 비슷한 일을 할 때 쓸 수 있는 재사용 프롬프트 템플릿을 만들어줘.
바뀌는 부분은 {{변수명}}으로 표시해줘.
```

> 자주 쓰는 템플릿은 각 서비스의 프로젝트(Projects), 커스텀 GPT(Custom GPTs), 젬(Gems), 스킬(Skills) 기능에 저장해 두면 매번 붙여 넣지 않아도 됩니다.

---

## 주의

- AI가 다듬은 프롬프트는 길고 장황해지기 쉽습니다. OpenAI는 최신 모델 가이드에서 **군더더기를 덜어낸 프롬프트**가 내부 코딩 에이전트 테스트에서 약 10~15% 더 좋은 점수를 냈다고 밝혔습니다(경향을 보여 주는 수치).
- "절대", "반드시", 대문자 강조가 늘어났다면 다시 빼세요. 최신 모델은 이런 강조를 지나치게 따릅니다.
- 개선 전후를 **같은 입력 3~5개로** 돌려 보고 결과를 비교하세요. ([docs/08-verification-and-evals.md](../docs/08-verification-and-evals.md))
