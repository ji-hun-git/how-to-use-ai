# Code of conduct

This project's issues and discussions are for improving an evidence-based guide. Keep them useful and kind.

**Expected:** Be respectful and assume good faith. Disagree with claims, not people. Back corrections with sources.

**Not acceptable:** Harassment, insults or personal attacks; discriminatory language or imagery; sharing someone's private information; spam or promotion unrelated to the guide.

**Enforcement:** The maintainer may edit, hide or delete comments, lock or close issues, and block accounts that break these rules. To report a problem privately, use GitHub's [report content](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam) feature.

This code follows the spirit of the [Contributor Covenant](https://www.contributor-covenant.org/).
