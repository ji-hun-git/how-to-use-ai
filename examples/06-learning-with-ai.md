# 예제 6. AI로 공부하기: 답을 받지 말고 생각을 키우기

> 생각은 AI에게 맡길 수 있어도, **이해**는 맡길 수 없습니다. (Karpathy의 말을 옮김)

---

## 연구가 보여 주는 것

- **답을 그냥 주는 AI는 실력을 떨어뜨렸습니다.** 펜실베이니아대 연구진이 튀르키예 고등학생 약 1,000명을 대상으로 한 실험(Bastani et al., *PNAS*, 2025)에서, 제한 없는 GPT-4를 쓴 학생은 연습 문제 점수가 48% 올랐지만 **AI 없이 본 시험에서는 17% 낮았습니다.**
- **힌트만 주는 튜터형 AI는 달랐습니다.** 답 대신 힌트를 주도록 설계한 버전은 연습 점수를 127% 올렸고, 시험 점수는 떨어뜨리지 않았습니다.
  (48%·127%는 2024년 워킹페이퍼 보도 기준 수치이고, *PNAS* 초록에서 확인되는 것은 시험 점수 17% 하락입니다.)
- MIT 미디어랩의 예비 연구("Your Brain on ChatGPT", 2025, 동료평가 전 프리프린트, 참가자 54명)에서는 에세이를 LLM으로 쓴 그룹이 뇌 참여도가 가장 낮고 자기 글을 잘 기억하지 못했습니다. 규모가 작고 반론도 나온 연구이므로 결론을 단정하지는 말되, 방향은 참고할 만합니다.

- 하버드 CS50은 이 교훈을 정책으로 만들었습니다. 자체 AI 튜터("CS50 덕")는 답을 바로 주지 않고 답 쪽으로 안내하도록 설계됐고, 답을 대신 써 주는 상용 AI는 과제에 쓸 수 없습니다.

**결론:** 공부할 때는 AI를 **답안지**가 아니라 **튜터**로 쓰세요.

## 튜터 모드 프롬프트

```text
너는 내 ___ 과목 튜터야. 나는 ___ 수준이야.
규칙:
- 정답이나 완성된 코드를 바로 주지 마.
- 내가 막히면 힌트를 한 단계씩만 줘. (작은 힌트 → 큰 힌트 순서)
- 내가 답을 말하면, 맞았는지 바로 말하지 말고 "왜 그렇게 생각했는지" 먼저 물어봐.
- 내가 "정답 보기"라고 하면 그때만 풀이를 보여줘.
오늘 공부할 주제: ___
```

## 개념 확인: 설명하게 하기 (파인만 기법)

```text
내가 ___ 개념을 설명해 볼게. 들어 보고
(1) 틀린 부분, (2) 빠진 부분, (3) 애매하게 넘어간 부분을 짚어줘.
칭찬은 빼고, 고칠 점이 없으면 없다고 해줘.

내 설명: ...
```

## 시험 대비: 문제 만들어 달라고 하기

```text
___ 단원에서 내가 헷갈리기 쉬운 지점을 노리는 문제 5개를 만들어줘.
한 문제씩 내고, 내가 답한 뒤에 채점과 해설을 해줘.
```

## 코딩 공부: 바이브 코딩과 구분하기

```text
나는 파이썬을 배우는 중이야. 이 코드를 직접 고쳐 주지 말고,
(1) 어디가 문제인지 위치만 알려 주고 (2) 어떤 개념을 찾아보면 되는지 알려줘.
내가 고친 다음에 다시 보여 줄게.
```

> Karpathy가 만든 말인 "바이브 코딩(vibe coding)"은 코드를 거의 읽지 않고 AI에게 맡기는 방식입니다. 주말 토이 프로젝트에는 괜찮지만, **배우는 중이라면** 위처럼 AI가 고쳐 주지 않게 막아 두세요.

## 자가 점검

- [ ] AI 없이 오늘 배운 내용을 3문장으로 설명할 수 있다
- [ ] AI가 준 설명 중 하나 이상을 교재나 공식 문서로 확인했다
- [ ] 정답을 보기 전에 스스로 시도한 흔적(메모, 오답)이 있다
